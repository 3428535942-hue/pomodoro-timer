# AGENTS.md — AI 操作规范（渐构世界模型驱动）

> 预测驱动 + 奥卡姆剃刀：每个操作、每个页面、每条规则都必须有存在的理由。所有方法论概念必须标注适用边界。

## 操作前自检（每次执行前必问）

1. **判别诊断**：当前情况属于哪类操作？该用哪条规则？（不跳过判别步骤）
2. **联结诊断**：这条规则能直接用于当前任务吗？还是需要组合多条规则？（不张冠李戴）
3. **记忆诊断**：我是机械执行还是真正理解了任务目标？（不记言代学）

## 五步流水线详细规范

### Step 1: 经验采集 → raw/

| 项 | 内容 |
|---|---|
| 输入 | 用户提供的文本、链接、笔记、文档 |
| 操作 | 通读→提炼核心主张→保留因果链→按模块聚合 |
| 输出 | raw/ 下模块化资料页，命名按**源内容名称**，每篇 < 200 行 |
| 概念类型对应 | 此步产出属于**对象概念**，对应**底层（对象层）**——是原始经验材料，不可修改 |
| 判别标准 | 每个主张可追溯到源；因果链未断裂；无断章取义；无一刀切拆分 |
| 禁止 | 擅自改写源内容；删除"不重要"段落；对 raw/ 做任何编辑 |

### Step 2: 概念建模 → atoms/

| 项 | 内容 |
|---|---|
| 输入 | Step 1 的 raw/ 页 |
| 操作 | 提取独立概念→标注**五组分类**（对象/属性/关系/操作/情境）→标注**抽象层级**（底层/中层/高层）→写 atoms/ 页 |
| 命名规则 | **概念全称**为文件名，中文，不含特殊字符。例如：`判联分析.md`、`概念五组.md` |
| 输出 | atoms/ 下 < 200 字概念页，可独立引用，脱离上下文能被理解 |
| 判别标准 | 五组分类+抽象层级已标注；独立可引用；无冗余拆分；无孤立页 |
| 奥卡姆剃刀检视 | 此概念能被其他页面引用吗？它是否只是另一个概念的换个说法？是否过度拆分了？ |
| 禁止 | 建无法被引用的孤立页；不标注类型+层级；超 200 字不拆；同一概念建多个页面 |

### Step 3: 判联整合 → topics/

| 项 | 内容 |
|---|---|
| 输入 | atoms/ 网络 + raw/ 经验锚点 |
| 操作 | 综合 ≥3 atom→topics/；标注**判联关系类型**（因果/层级/类比/对立/代理）；检测矛盾→`> ⚠️ 矛盾：` |
| 命名规则 | **主题全称**为文件名，中文。例如：`渐构世界模型-方法论总纲.md` |
| 输出 | topics/ 主题页 + 更新 index.md |
| 判别标准 | 每个 topic 综合 ≥3 atom；判联关系类型明确；矛盾已标记；有 raw/ 锚点 |
| 禁止 | 建 <3 atom 的虚胖 topic；忽略矛盾；无 raw/ 锚点的纯空中楼阁主题页 |

### Step 4: 适用校验

| 项 | 内容 |
|---|---|
| 输入 | 前 3 步产出的所有新页面 |
| 操作 | 每方法论 atom + `## 适用边界`（成立条件+不成立情况/反例）；每 topic + `## 何时不适用`；检测脱离现实 |
| 核心测试 | "在什么条件下这个知识是错的？""有没有一个活生生的反例？""这页与 raw/ 中的经验锚点连通吗？" |
| 判别标准 | 至少一个反例；与 raw/ 保持连通；无纯抽象断言；无不标边界的"普世真理" |
| 禁止 | 留空适用边界；使用"总是""绝对""所有""必然"等无边界表述；建无 raw/ 锚点的纯推理页 |

### Step 5: 规则内化

| 项 | 内容 |
|---|---|
| 输入 | 经过前 4 步检验的方法论 |
| 操作 | 属于**操作概念**且可执行的→嵌入 CLAUDE.md / AGENTS.md 作为内置规则；纯理论/描述性的→保留在 atoms/ |
| 产出 | 更新后的规则文件，每条规则必须：具体到操作动作、有自检标准、与旧规则无冲突 |
| 禁止 | 把理论描述当规则写（如"要善于预测"无法执行）；把宽泛原则不加工直接写进去；覆盖已有良好规则 |

## 七步渐构分析（学习辅助模式专用）

当用户说"学习/复习/检验/帮我理解"时，启动此模式，按七步流程分析：

1. **判断推测类型**：经验预测还是模型预测？→ 决定知识建构方向
2. **明确输入输出空间**：此知识"适用于什么范围？能推测出什么？"→ 标注适用边界
3. **拆组任务**：需要建构哪些判别模型？哪些联结模型？→ 用判联分析拆解
4. **分析知识类型**：五组中的哪一组？什么抽象层级？→ 决定概念页分类
5. **分析学习材料**：知识库中哪些 atoms/ 可作判别模型？哪些是联结模型？材料是否覆盖新颖情况？
6. **分析学习方式**：此知识适合创验学习（自己推演验证）还是继承学习（重建他人模型）？
7. **执行验证**：能否对未见情况做出正确预测？

### 判联诊断（3 步排查学习困难）

1. **判别诊断**：用户能判断什么情况该用什么知识吗？→ 不能 → **对象层丢失**，需补判别模型
2. **联结诊断**：用户能用已有知识推演新情况吗？→ 不能 → **判联错配**或模型未建构
3. **记忆诊断**：用户能重现已学内容但无法应用于新情况吗？→ 能 → **记言代学**，需从"背"转"学"

## 收录顺序规则

1. 严格按 5 步流水线顺序执行，**不跳步**（跳过 Step 4 适用校验是最高频错误）
2. 前置概念必须先收录（后续概念依赖的前置概念缺失会导致**对象层丢失**）
3. 不产生新概念的单篇→在 course-progress.md 标记"已阅/无新概念"，不强制建页
4. **奥卡姆剃刀约束**：每批最多 5 篇，每篇最多 5 个原子概念，不一次超 10 页
5. 每层收录完毕后暂停运行健康检查：矛盾扫描、孤立页检测、过时标记、适用边界完整性检查

## 健康检查清单（每批收录后自动执行）

- [ ] 是否有新建 atoms/ 未标注**五组分类**？
- [ ] 是否有新建 atoms/ 未标注**抽象层级**？
- [ ] 是否有 topic 未标注**判联关系类型**？
- [ ] 是否有方法论概念未标注**适用边界**？
- [ ] 是否有未链接到 raw/ 的纯抽象页？（脱离现实）
- [ ] 是否有孤立页？（无任何 [[链接]] 指向它，也不指向任何页面）
- [ ] 是否有新概念与前 4 步产生的概念矛盾？（矛盾扫描）
- [ ] 是否有新概念依赖的前置概念尚未建页？（对象层丢失检测）
