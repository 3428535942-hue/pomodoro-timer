# AGENTS.md — AI 操作规范

> 预测驱动 + 奥卡姆剃刀：每个操作、每个页面、每条规则都必须有存在的理由。所有方法论概念必须标注适用边界。

## 五步流水线详细规范

### Step 1: 经验采集
| 项 | 内容 |
|---|---|
| 输入 | 用户提供的文本、链接、笔记 |
| 操作 | 通读 → 提炼核心主张 → 保留因果链 → 按模块聚合到 raw/ |
| 输出 | raw/ 下的模块化资料页（每篇 < 200 行） |
| 判别标准 | 每个主张可追溯到源；因果链未断裂；无断章取义 |
| 禁止 | 擅自改写源内容；删除看似"不重要"的段落 |

### Step 2: 概念建模
| 项 | 内容 |
|---|---|
| 输入 | Step 1 的 raw/ 页 |
| 操作 | 提取独立概念 → 五组分类 → 标注抽象层级 → 写 atoms/ 页 |
| 输出 | atoms/ 下 200 字以内概念页，可独立引用 |
| 判别标准 | 脱离上下文能独立理解；类型+层级已标注；无冗余拆分 |
| 禁止 | 建无法被引用的孤立页；不标注类型层级；超 200 字不拆 |

### Step 3: 判联整合
| 项 | 内容 |
|---|---|
| 输入 | atoms/ 网络 + raw/ |
| 操作 | 综合 ≥3 个 atom → topics/；标注判联关系类型；检测矛盾 |
| 输出 | topics/ 主题页 + 更新 index.md |
| 判别标准 | 每个 topic 综合 ≥3 atom；判联关系明确；矛盾已标记 |
| 禁止 | 建只链接 <3 个 atom 的 topic；忽略矛盾 |

### Step 4: 适用校验
| 项 | 内容 |
|---|---|
| 输入 | 前 3 步产出的所有新页面 |
| 操作 | 每页标注适用条件+不成立情况；至少一个反例；检测脱离现实 |
| 输出 | 每个方法论 atom + `## 适用边界`；每个 topic + `## 何时不适用` |
| 判别标准 | 至少有一个反例；与 raw/ 保持连通；无纯抽象断言 |
| 禁止 | 留空"适用边界"；使用"总是""绝对""所有"等无边界表述 |

### Step 5: 规则内化
| 项 | 内容 |
|---|---|
| 输入 | 经过前 4 步检验的方法论 |
| 操作 | 可操作的 → CLAUDE.md / AGENTS.md；不可操作的 → 保留在 atoms/ |
| 输出 | 更新后的规则文件 |
| 判别标准 | 每条规则可被直接执行；有自检标准；新旧规则无冲突 |
| 禁止 | 把理论描述当规则写；覆盖已有良好规则 |

```markdown

- 五组分类：[对象/属性/关系/操作/情境]
- 抽象层级：[底层/中层/高层]

## 适用边界（仅方法论概念需要）
- 成立条件：
- 不成立情况 / 反例：

source: [[../raw/源文件]]
```

## 关键概念

- 因果链：
- 层级关系：
- 概念代理：

## 何时不适用
## 脱离现实风险
- [ ] 是否有经验锚点？

last_updated: <日期>
sources: [[../raw/源文件]]

## 格式约束

- 文件名：中文，不含特殊字符，`.md` 后缀
- 链接：`[[页面名]]`
- 日期：`YYYY-MM-DD`
- 文件第一行：`> 一句话摘要`

## 收录顺序规则

1. 严格按课程顺序收录（不跳集），确保前置概念先收录
2. 不产生新概念的单集 → 在 course-progress.md 标记"已阅/无新概念"
3. 每批最多 5 集，每集最多提取 5 个原子概念
4. 每层收录完毕后暂停，运行健康检查（矛盾扫描、孤立页检测、过时标记）
