# 个人 AI 知识库规则 — 渐构世界模型驱动

> **一切操作服从一条根本原理：预测驱动。** 知识库存在的唯一目的是让你能对未见之事做出更准的预测。不服务于预测的知识是噪音。

## 底层哲学：渐构世界模型

### 认知根基（来自课程第1–5集）

1. **预测是生命的本质**：生命通过预测来规避危险、获取资源。学习=提升预测能力。建每个页面前先问——"看了这页，我能预测什么之前预测不了的事？"
2. **经验预测 vs 模型预测**：经验预测是"上次这样→这次也这样"（同层类比）；模型预测是"因为某种机制→所以在任何情况下都会这样"（跨层推演）。知识库的目标是帮你从经验预测升级到模型预测。
3. **无穷现实**：物质世界有无穷多的变化维度，任何模型都只是从中抽取了几个维度。不追求"完整描述"，只追求"对当前目标有用的简化"。一页一概念、一概念一目的。
4. **适用判别**：有了模型还不够，还要知道"此模型适用于什么范围"。每个方法论概念必须标注适用边界——在什么条件下成立、什么条件下不成立、至少一个反例。

### 概念理论（来自课程第6–15集）

5. **概念五组** — 所有知识页按此体系分类，不可省略：
   - **对象概念**：指代存在物（如"知识库""神经元""语言"）
   - **属性概念**：指代特征/状态（如"抽象""具体""流畅"）
   - **关系概念**：指代联系（如"因果""层级""代理""类比""对立"）
   - **操作概念**：指代动作/过程（如"预测""学习""分类""抽象"）
   - **情境概念**：指代条件/场景（如"教育环境""原始社会""紧急状态"）
6. **抽象层级** — 每个概念标注其在"下上结构"中的位置：
   - **底层（对象层）**：可直接感知或观察的具体事物/行为
   - **中层（共象层）**：从多个底层概念中归纳出的共性模式
   - **高层（元认知层）**：关于认知本身的认知，操作概念和关系概念多在此层
7. **概念世界**：人脑不与物质世界直接接触——通过判别模型将信号映射到概念世界，在此推理后再映射回行动。概念划分决定了"看到什么世界"。新概念=新视界。
8. **判别模型**：从任意事物到"属于此概念/不属于此概念"的二元分类规则。创造概念时必然同时创造出正概念和负概念（一分必出二）。
9. **类别固有观 vs 类别建构观**：概念不是客观存在的"自然类"，而是人为建构的分类工具。不存在"正确的概念"，只存在"对当前目的有用的概念"。

### 判联分析（来自课程第20–21集）

10. **判联分析**：任何知识的应用都可拆为两步——(1) 判别：判断当前情况属于哪个类型（判别模型）；(2) 联结：调用该类型对应的规则做推演（联结模型）。学习困难的三类根源：
    - **对象层丢失**：有联结模型但缺判别模型 → 会背公式但不知道什么时候用
    - **判联错配**：用错误的概念去套规则 → 张冠李戴
    - **乱猜概念**：不理解学科正式定义，自己"悟"了一个含义 → 自建体系与学科体系不兼容

### 学习机制（来自课程第16–30集）

11. **学习 vs 记忆**：学习=建构模型（可用于推演新情况）；记忆=存储信息（只能原样重现）。知识库中的概念页必须是"学习"而非"记忆"——脱离上下文后仍能独立用于推演。
12. **创验学习 vs 继承学习**：创验=自己从经验中推导验证出模型；继承=重建他人已有的模型（效率高，但有被歪曲的风险）。知识库兼用两者，优先标注来源和推理链。
13. **渐构分析** — "分析学习方法的方法"（七步流程）：
    1. 判断推测类型（经验预测还是模型预测？）
    2. 明确输入输出空间（此知识适用于什么范围？能推测出什么？）
    3. 拆组学习任务（拆为判别模型+联结模型的建构）
    4. 分析知识类型（五组中的哪一组？什么抽象层级？）
    5. 分析学习材料（是否包含必要经验数据？是否覆盖新颖情况？）
    6. 分析学习方式（建构还是记忆？创验还是继承？）
    7. 执行并验证（能否预测未见情况？）

## 五步流水线（操作层）

> 每一批新资料进入知识库时，严格按此顺序执行。命名和分类必须使用上述渐构术语。

### Step 1: 经验采集 → raw/

| 项 | 规范 |
|---|---|
| 输入 | 用户提供的文本、链接、笔记、文档 |
| 操作 | 通读→提炼核心主张→保留因果链→按模块聚合 |
| 输出 | raw/ 下模块化资料页，每篇 < 200 行 |
| 命名 | 按来源内容命名，保留原始语境 |
| 自检 | 每个主张可追溯到源；因果链未断裂；无断章取义 |

### Step 2: 概念建模 → atoms/

| 项 | 规范 |
|---|---|
| 操作 | 从 raw 中提取独立概念→标注**五组分类+抽象层级**→写 atoms/ 页 |
| 命名 | **概念全称**，中文，不含特殊字符 |
| 约束 | 每页一个概念，< 200 字。必须标注五组分类（对象/属性/关系/操作/情境）和抽象层级（底层/中层/高层） |
| 奥卡姆剃刀 | 能被引用吗？够独立吗？过度拆分了吗？无引用价值的页不建 |
| 自检 | 脱离上下文能独立理解；类型+层级已标注；无冗余拆分 |

### Step 3: 判联整合 → topics/

| 项 | 规范 |
|---|---|
| 操作 | 综合 ≥3 个 atom → topics/；标注**判联关系类型**；检测矛盾 |
| 命名 | **主题全称**，中文 |
| 关系类型 | 必须标注：因果/层级/类比/对立/代理（至少一种） |
| 自检 | 每个 topic 综合 ≥3 atom；判联关系明确；矛盾已标记 `> ⚠️ 矛盾：` |
| 禁止 | 建只链接 <3 个 atom 的 topic；忽略矛盾 |

### Step 4: 适用校验

| 项 | 规范 |
|---|---|
| 操作 | 每页标注**适用条件+不成立情况**；至少一个**反例**；检测**脱离现实** |
| 方法论 atom | `## 适用边界` — 成立条件 + 不成立情况/反例 |
| topic | `## 何时不适用` — 覆盖范围边界 |
| 核心问题 | "在什么情况下这个知识是错的或不适用的？" |
| 自检 | 至少有一个反例；与 raw/ 保持连通；无纯抽象断言 |
| 禁止 | 留空适用边界；使用"总是""绝对""所有"等无边界表述 |

### Step 5: 规则内化

| 项 | 规范 |
|---|---|
| 操作 | 可操作的→ CLAUDE.md / AGENTS.md | 理论性的→保留在 atoms/ |
| 标准 | 每条规则必须：具体到操作动作、有自检标准、与旧规则无冲突 |
| 禁止 | 把理论描述当规则写；覆盖已有良好规则 |

## 收录顺序规则

1. 严格按内容本身的逻辑顺序收录，确保**前置概念先收录**（后续概念依赖的前置概念必须先建页）
2. 不产生新概念的内容 → 在 course-progress.md 标记"已阅/无新概念"
3. **每批最多 5 条内容，每条最多提取 5 个原子概念**（奥卡姆剃刀约束）
4. 每层收录完毕后暂停，运行健康检查：矛盾扫描、孤立页检测、过时标记

## 书写规范

- **文件首行**：`> 一句话摘要`（blockquote 格式）
- **概念页额外标注**：五组分类 + 抽象层级
- **链接**：`[[页面名]]`（Wikilink 语法）
- **矛盾标记**：`> ⚠️ 矛盾：<描述>`
- **过时标记**：`> ⚠️ 过时：<原因>`
- **待办**：`- [ ] 待验证项`
- **日期**：`YYYY-MM-DD`
- **文件名**：中文，不含特殊字符，`.md` 后缀

## 反遗忘机制（每页知识附带）

- "如果你忘了这页，你能从哪些已知概念推导出它？"（防止记言代学）
- "你能举出一个这页知识不适用的情况吗？"（防止知识坍缩）

## 禁止事项

- 不改 raw/ 下的原始文件（经验锚点不可篡改）
- 不建空页面
- 不删内容（过时标记即可）
- 不一次超 10 页（分批执行，奥卡姆剃刀约束）
- 不建无适用边界的空泛断言
- 不建无 raw/ 经验锚点的纯抽象页（脱离现实）
- 不跳过前置概念（对象层丢失会引发知识体系瘫痪）
