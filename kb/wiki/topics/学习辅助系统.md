> 将渐构·世界模型的方法论转化为知识库内置的学习辅助能力——从判联诊断到个性化学习路径，从自检问题到反遗忘机制。

## 核心功能

### 1. 判联诊断（三步排查法）

当你遇到学习困难（考试不会用、看书看不懂、学完就忘），按以下流程诊断：

```
你的问题是什么？
├── 不知道什么时候用什么知识？ → 对象层丢失
│   → 解决：需要补判别模型（看 atoms/ 中该概念的"适用边界"）
├── 知道用哪个但不会推演？ → 判联错配
│   → 解决：检查是否用错了概念归类，看 topics/ 中的判联关系
└── 能背出来但不会用于新情况？ → 机械记忆
    → 解决：从"背定义"转为"建模型"，用下方"自检问题"
```

### 2. 个性化学习路径

基于诊断结果，知识库会自动规划：
1. **明确输入输出**："这个知识用于什么场景？能推测出什么结论？"
2. **拆解任务**：需要建构哪几个判别模型？哪几个联结模型？
3. **推荐路径**：先看哪个 atoms/（概念），再看哪个 topics/（综合），最后看哪个 raw/（原始经验）
4. **推荐方式**：能自己推导吗？（创验）还是需要继承他人模型？（继承）

### 3. 反遗忘机制

每个概念页附带两个自检问题：
- **推演自检**："如果你忘了这页，你能从哪些已知概念推演出它？"
- **边界自检**："你能举出一个这页知识不适用的情况吗？"

这两个问题分别防止"记言代学"（把文字当知识记）和"知识坍缩"（把模型当成适用所有情况的真理）。

## 判联分析

- **因果链**：用户学习目标 → 判联诊断 → 个性化路径 → 执行 → 反遗忘自检 → 验证
- **层级关系**：学习辅助系统（高层元认知）→ 渐构分析七步法（中层操作）→ 具体概念页（底层知识）
- **概念代理**：知识库中的 atoms/ 和 topics/ 本身成为用户认知的"代理"——帮你思考那些你还没内化的概念

## 何时不适用
- 肌肉记忆类技能（运动、乐器）——本系统主要用于概念性知识的建构
- 纯情感体验类学习——本系统分析的是认知层面
- 用户没有明确学习目标时——需要先明确"想预测什么未见情况"

## 脱离现实风险
- [ ] 自检问题是否真的能触发用户思考？还是变成形式？
- [ ] 判联诊断的准确性有多少？是否需要人工校准？
