> 渐构·世界模型课程的核心方法论框架：将"人类如何学习"的认知原理，转化为知识库的日常操作规则。

## 五大模块

| 模块 | 集数 | 核心问题 |
|------|------|---------|
| 基础认知层 | 1-5 | 生命如何通过预测生存？经验的局限是什么？模型如何超越经验？ |
| 概念理论层 | 6-15 | 知识由什么构成？概念如何分类？抽象层级如何运作？ |
| 学习方法层 | 16-30 | 如何看书？如何分析学习方法本身？语言学习的底层机制？ |
| 记忆机制层 | 31-35 | 学习和记忆有什么区别？何时能用记忆代替学习？ |
| 元认知层 | 36-38 | 原创性从何而来？现代教育为何不适应智能时代？ |

## 已提取的五步流水线

```
经验采集 → 概念建模 → 判联整合 → 适用校验 → 规则内化
```

| 步骤 | 核心操作 | 对应课程 |
|------|---------|---------|
| Step 1: 经验采集 | 通读→提炼→保留因果链→聚合到 raw/ | 第2集（经验预测） |
| Step 2: 概念建模 | 提取独立概念→五组分类→标注抽象层级→atoms/ | 第6集（五组概念）+ 第8集（抽象层级） |
| Step 3: 判联整合 | 综合概念→topics/→标注关系类型→检测矛盾 | 第20-21集（判联分析） |
| Step 4: 适用校验 | 标注适用边界→至少一个反例→检测脱离现实 | 第5集（适用判别）+ 第25集（脱离现实） |
| Step 5: 规则内化 | 可操作的→规则文件；不可操作的→知识页 | 第14集（革新的推力）+ 第15集（重塑三观） |

## 已嵌入的核心原则

1. **预测驱动**：建页面的目的是推演未见之事，不是堆积信息
2. **经验→模型**：raw/ 是经验锚点，atoms/ 是抽象模型，topics/ 是连接器
3. **无穷现实**：不追求"完整"，只追求"有用"
4. **适用边界**：每个概念标注何时成立、何时不成立
5. **奥卡姆剃刀**：如无必要，勿增页面。不建无引用价值的页

## 判联分析

- **因果链**：预测需求 → 经验积累 → 模型提炼 → 适用判别 → 规则生成
- **层级关系**：基础层 → 概念层 → 方法层 → 规则层
- **概念代理**：五类概念中，"操作概念"是最适合转化为规则的
